# Plan: Anatomy of a Document

This file shows where a document's writing plan lives. It is excluded from the build (`**/plan.md` in `conf.py`), so it never appears on the site.

## 种子

Show a new author which files make up one document.

## 读者

Anyone writing their first document in this knowledge base.

## 核心观点

A document is a folder; only `README.<ext>` reaches the site.
