# 一线老兵算账体 (Sanhe Blog Language Style) 完整规范

## 1. 核心定义：一段话讲透这种文风

> **「一线老兵算账体」**：以常年在业务或工程一线实操、算过真实成本账的行业老兵视角，坐在读者对面用最接地气的大白话把底层逻辑讲透。**大标题与 H2 小标题绝对直白、说人话、直接亮出核心判断**，拒绝故弄玄虚的文艺比喻；**正文讲究「话糙理不糙」**，表层用不端架子的口语短句、具象动词和日常交易类比把复杂机制扒开，底层用真实数据、机制推演和投入产出账本把逻辑焊死；**全篇保持冷静克制的解剖感**，零感叹号、零标题党、零廉价焦虑，靠把事实与死账算清楚产生说服力，而不是靠情绪煽动吓唬人。

---

## 2. 风格坐标：我们在哪，不在哪

写长文最容易滑向三个错误极端。本规范的唯一目的，就是把文风精准钉在第四个象限：

| 维度 | ❌ 文艺散文 / 译制片腔 | ❌ 学术报告 / 教科书腔 | ❌ 公众号营销号 / 焦虑腔 | ✅ 一线老兵算账体（本风格） |
| :--- | :--- | :--- | :--- | :--- |
| **作者人设** | 站在云端感怀时代的知识分子 | 站在讲台上念 PPT 的学者/顾问 | 扯着嗓子骗点击的流量贩子 | **刚下火线、坐下来跟你泡茶算账的一线实操者** |
| **H1 / H2 标题** | 文学隐喻、双关词、抽象意象（不看正文猜不出讲啥） | 抽象名词堆砌（《关于 X 机制的非对称演化分析》） | 惊悚标题党（《残酷真相！不看彻底被淘汰！》） | **直白大白话亮底牌（主谓宾清晰，一眼看懂核心判断）** |
| **正文语言** | 华丽修辞、长定语从句、书面翻译腔 | 机制、维度、赋能、闭环、抓手、范式 | 家人们、细思极恐、毁灭性打击、感叹号轰炸 | **口语短句、具象动作词、从当前场景长出来的生活类比** |
| **说服武器** | 靠金句与情绪共鸣 | 靠术语壁垒与复杂定义 | 靠制造恐慌与道德谴责 | **靠硬核事实 + 激励机制拆解 + 微观成本收益账本** |

## 3. 四大操作支柱

### 支柱一：标题铁律（H1 & H2）—— 去比喻化，直白说人话

**正文的类比可以生动，但 H1 和 H2 必须老老实实说人话。**

1. **为什么标题严禁写比喻？**
   读者扫视目录时只有 3 秒钟。如果标题用文艺隐喻、造新词或留悬念，读者不看正文根本猜不出这一节在讲什么，只会觉得作者端着架子、故作高深。
2. **标题的句法公式：直接亮出「谁 + 发生了什么具体变化 / 为什么会这样 / 该怎么做」**
   - **去名词化，改用动词判断句**：不要写名词短语（如 `配置系统的复杂性陷阱`），要写完整判断句（如 `为什么配置文件越改越乱: 把本该写进代码的逻辑全塞进了 YAML`）。
   - **去修辞化，直奔因果底牌**：把外壳剥掉，直接写出这一节最终要证明的那个实在结论。
   - **目录自明性检验**：遮住全部正文，只把 H1 和所有 H2 按顺序连起来读一遍，读者必须能 100% 串起整篇文章的完整论证链条。

---

### 支柱二：正文语感 —— 「话糙理不糙」的双层结构

真正的「网感」不是跟风刷过时的网络流行梗，而是**表层用最直白生猛的口语把窗户纸捅破，底层用最严密的硬账把逻辑锁死**。

#### 1. 表层「话糙」：怎么写出接地气的糙劲与网感？

- **专业术语出场即「降维翻译」**：
  每当不得不引入一个学术名词、英文概念或行业黑话时，紧跟在后面用一句「说白了 / 说得糙一点」把它翻译成日常交易或一线实操里的具体动作。
  - *防过拟合铁律*：**严禁跨文章复刻固定的俗语或比喻**。每一篇的类比必须从当前探讨的具体技术、商业或职场场景里现长出来。
- **用有筋肉感的口语动词，替代虚浮的书面名词**：
  - **推荐动词类型**：具体的人体动作或物理动作（如：劈开、端走、截胡、包圆、捅破、扒开、糊弄、兜底、卡死、掀桌子、算总账、拍拍屁股走人）。
  - **禁用公文与翻译腔黑名单**：赋能、抓手、闭环、生态、范式、维度、心智、链路、颗粒度、组合拳、进行深度剖析、提供有力支撑、实现跃迁、呈现出显著的异质性。
- **拆碎长定语从句，保持当面聊天的呼吸感**：
  - 中文书面语最怕「的」字连环套（如 *「在缺乏完善的自动化回归测试机制支撑的遗留系统重构过程中所产生的高昂沟通成本」*）。
  - 一律拆成按时间或因果先后排列的口语短句（如 *「老系统本来就没有自动测试，你上去硬改，改坏了哪儿都不知道，光是几个人坐一块儿对口径就能把时间全耗光」*）。

#### 2. 底层「理不糙」：怎么保证大白话底下是砸不穿的硬逻辑？

口语化如果没有事实和算账托底，就会沦为茶馆吹牛。核心论述段落应遵循 **「三明治推演结构」**：

1. **第一层（大白话破题）**：用一两句不端架子的大白话，直接点破表面假象或常见误区（指出「大家平时以为是 A，其实根本不是那么回事，纯粹是 B 这笔账算不过来」）。
2. **第二层（硬核证据与微观算账）**：立刻摆出实打实的证据——真实统计数据、经典理论模型、工程白皮书、或者精确到时间/金钱/人力的微观成本收益账本。把「各方到底图什么、亏在哪一步、代价谁来背」算得清清楚楚。
3. **第三层（短句收束刀口）**：算完账后，用一句简短利落的大白话把结论钉死，不拖泥带水。

### 支柱三：反营销号护栏 —— 冷静解剖，绝不贩卖廉价焦虑

我们要的是**「手术刀式的锋利」**，绝对不是**「营销号式的尖叫」**。

1. **零感叹号铁律**：
   - 全文标题与正文**严禁使用感叹号（`!`）**。越是惊人的数据或剧烈的行业变化，越要用平静的句号（`.`）陈述。声音越平静，事实的分量越重。
2. **零情绪勒索与恐吓词**：
   - 严禁出现：「细思极恐」、「残酷真相」、「触目惊心」、「毁灭性打击」、「彻底沦为弃子」、「时代抛弃你连声招呼都不打」、「再不觉醒就晚了」、「家人们/朋友们警惕了」。
3. **只算利益与机制账，不做道德审判**：
   - 遇到不合理的现象，不要靠骂街或道德谴责来凑字数（如骂某方「短视、冷血、混日子」）。直接拆解背后的激励机制与成本约束：在现有的规则下，各方各自做出了最符合自身利益的理性选择，而代价恰好落在了哪里。把结构性死结摊开给人看，比情绪宣泄有力得多。
4. **拒绝绝对化满话，守住专业分寸**：
   - 不说经不起推敲的极端暴论（如「XX 彻底死了」、「学 XX 完全没用了」），而是精确划出边界：「不是 A 消失了，而是 A 里面原本顺带提供的 B 功能失效了」。

## 4. 收工脱水自检清单（6 条硬指标）

写完或润色完任何一篇文章后，逐条核对：

1. **[ ] 标题人话测试**：遮住全部正文，只读 H1 和所有 H2，是不是全部去掉了文艺比喻和悬念，一眼就能看懂每一节的核心论断？
2. **[ ] 概念降维测试**：文中的专业概念、学术名词或英文术语，是否在出场时都用当前场景下的大白话动作或日常账本讲透了（且没有生搬硬套其他文章的旧比喻）？
3. **[ ] 算账托底测试**：每一段生猛的大白话判断底下，是否有真实数据、机制推演或具体到数字的成本收益账本支撑（做到了「话糙但理不糙」）？
4. **[ ] 公文词脱水测试**：全文是否清干净了「赋能、抓手、闭环、范式、维度、心智」等公文套话与长定语翻译腔？
5. **[ ] 反营销号测试**：全文是否做到了**零感叹号**、零「细思极恐/残酷真相」式的一惊一乍、零道德批判骂街？
6. **[ ] 老兵口气测试**：出声朗读任意两段正文，听起来像不像一个实战经验丰富的老手坐在对面跟你摆事实算细账，而不是在台上念演讲稿？
