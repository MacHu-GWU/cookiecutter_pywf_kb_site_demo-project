# Spec: 语言与标点

> 管辖范围: 作者这边写的所有文字 (`README.md` 正文和 `description`, `plan.md`) 用什么语言, 什么标点. `resources/` 里别人的原文不受约束, 原样保留.

---

## 1. 语言跟站点走

文档用站点的语言写: `docs/source/conf.py` 的 `language` (`en` 是英文, `zh_CN` 是中文). 专业术语, 产品名, 库名, 函数名保留英文原文, 不硬翻. 代码, 命令, 配置项, 报错信息原样保留.

英文站点只需要第 1 节. 下面第 2, 3 节只管中文文档.

---

## 2. 中文文档: 标点全部英文半角

**所有标点都用英文半角**, 逗号 `,` 句号 `.` 冒号 `:` 问号 `?` 括号 `( )` 引号 `" "`, 顿号也写成逗号. 标点后面跟一个空格, 中文和英文或数字之间留一个空格.

```text
不要: 这一步用 <某个工具>（命令行版）跑一遍，几秒钟就完事。
而要: 这一步用 <某个工具> (命令行版) 跑一遍, 几秒钟就完事.
```

本 family 写或改的文档一律半角; 顺手碰到别人写的旧文档时, 作者没要求就不去改它.

---

## 3. 中文文档: 用 c2ep 统一

写完或改完, 用 `c2ep` 跑一遍. 先 `--dry_run` 看会改哪几行:

```bash
uvx --from "chinese_to_english_punctuation>=0.1.3" c2ep file --skip_code --path <文件路径> --dry_run
uvx --from "chinese_to_english_punctuation>=0.1.3" c2ep file --skip_code --path <文件路径>
```

已知它会误伤, 跑完要检查并手动改回来:

- **不加 `--skip_code` 时, 代码块和行内代码里的标点它也改**, 包括代码里有意写的全角字符串和上面这种故意展示的反例. 所以命令里总是带 `--skip_code`.
- **`/` 后面紧跟中文时会插空格**, 比如 `$10/月` 变成 `$10/ 月`.
- **MyST 语法.** 检查 `{ref}`, `(<label>)=`, ```` ```{directive} ```` 和 `:option:` 行有没有被改坏.

`blog_utils.py check` 会在正文 (代码块和行内代码以外) 发现全角标点时给 WARN.
